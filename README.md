# Personal Portfolio Website

A modern, responsive personal portfolio website for Thushara Sandeepani - Computer Science Student.

## 🌟 Features

- **Modern Design**: Clean and professional UI with smooth animations
- **Responsive**: Fully mobile-friendly design
- **Interactive**: Smooth scroll, hover effects, and animations
- **Sections**: Hero, About, Skills, Projects, Education, Contact, Footer

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- JavaScript (Intersection Observer, Smooth Scroll)
- Google Fonts (Inter, Poppins)
- Devicons (Skill icons)
- Font Awesome (Icons)

## 📁 Project Structure

```
portfolio/
├── index.html              # Main HTML file
├── css/
│   └── styles.css          # All styles
├── js/
│   └── script.js           # JavaScript functionality
├── assets/
│   └── images/
│       └── profile-placeholder.svg
├── .gitignore
└── README.md
```

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/thushara-sandeepani/portfolio.git
   ```

2. Open `index.html` in your browser

## 📝 Customization

1. Replace the profile placeholder image in `assets/images/`
2. Update personal information in `index.html`
3. Modify colors in `css/styles.css` (CSS variables at the top)
4. Add your own projects in the Projects section
